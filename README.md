# FITRIA — Professional Portfolio Web App

A static, responsive portfolio website built for editing in Visual Studio Code.

## Run locally (no payment required)
1. Extract the ZIP archive.
2. In VS Code, choose **File → Open Folder** and select `fitria-portfolio-app`.
3. Open `index.html` using the **Live Server** extension, or double-click `index.html` to preview in a browser.
4. Use the sidebar to explore project samples. Click **View case study** to see sample evidence.

## Customize
- `index.html`: profile text, experience, contact links and sidebar.
- `script.js`: the `PROJECTS` array controls cards, filters and case study descriptions.
- `style.css`: colors, spacing, layout and the dark-mode styles.
- `assets/`: portraits, screenshots and CV file. Replace images while keeping the file names or updating paths.

## Notes and transparency
- The website is intended as an *aspiring* Virtual Assistant and Digital Operations portfolio, not a claim of senior web-engineering proficiency.
- Spreadsheet projects are labeled as training/case-study work. One example screenshot visibly includes a `#N/A` formula error, acknowledged in its project description. Verify and improve Excel formulas before claiming all outputs are final.
- Website screenshots in the original portfolio are labeled as beginner learning projects, with AI-assisted work explicitly mentioned; functionality of the original interfaces has not been verified.
- Sample document contents are summarized in custom thumbnails; these are illustrative representations of the uploaded examples, not screenshot evidence of a customer deployment.
- The CV file is the provided source DOCX. Check all personal information and dates before public sharing. For privacy, do not add sensitive client, employee or customer details to a public portfolio.
- Google Fonts load online; system fallback fonts work offline. Everything else functions locally without external services.
- Publishing to a website hosting service is optional, and not needed to preview locally in VS Code.
