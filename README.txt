FITRIA SOPIANA PORTFOLIO - GitHub Pages

Files: index.html, style.css, script.js + all images in the same folder (no build step, no dependencies except Google Fonts).

How to publish:
1. Open github.com/fitriasopiana/Fitriasopianaportofolio
2. DELETE the old files first (important): payroll-allowance.png, salary-lookup.png, employee-payroll.png, design-gallery.webp, fitria-formal.webp, README.md, UPLOAD-GITHUB.txt, and the old index.html/style.css/script.js if you prefer a clean start. Old images with #N/A errors stay publicly reachable if you leave them.
3. Add file > Upload files. Drag ALL files from this folder (not the folder itself, not the ZIP).
4. Commit changes to main. Wait 1-3 minutes, then open the site and press Ctrl+Shift+R.
5. Check: every image loads, the menu works on your phone, and your email/LinkedIn links open.
